# VlctyCrrctr ユーザーマニュアル

**VlctyCrrctr** は、入力された MIDI ノートのベロシティをリアルタイムに補正する
VST3 プラグインです。録音済みの MIDI データを書き換えることなく、音源の手前に
挿すだけでベロシティを固定・リマップ・クリップできます。

## インストール

ビルドした `.vst3` を `C:\Program Files\Common Files\VST3` にコピーしてください。
DAW からはインストゥルメント(`VlctyCrrctr`)として認識されます。

## セットアップ

1. DAW 上でインストゥルメントとして VlctyCrrctr を起動します。
   (MIDI エフェクトとしてチェーンに挿せるように、無音のダミーステレオ出力を
   持つインストゥルメントとして登録されています。)
2. MIDI 入力を VlctyCrrctr にルーティングし、VlctyCrrctr の MIDI 出力を
   鳴らしたい音源に接続します。(ルーティング方法は DAW によって異なります。)
3. パラメータ設定は DAW のプロジェクトと一緒に保存・復元されます。

## 補正モード (Correct Type)

GUI 上部のコンボボックスで切り替えます。

| モード | 動作 |
| --- | --- |
| **Through** | ベロシティを変更せずにそのまま通過させます。 |
| **Fix** | すべてのノートオンのベロシティを *Fix* の値に固定します。 |
| **Remap** | 入力ベロシティの全範囲 (1–127) を *Min*–*Max* の範囲に線形にマッピングします。 |
| **Clip** | ベロシティを *Min*–*Max* の範囲に収まるようにクランプします。 |

### 補足・注意事項

- ベロシティ 0 のノートオン(MIDI 慣習上のノートオフ)は、どのモードでも
  そのまま通過します。
- **Clip** モードで *Min* > *Max* と設定した場合は不正な設定とみなし、
  ノートをミュートします(ベロシティ 0 を出力)。意図的にベロシティゲートとして
  使うこともできます。
- ノートオフやコントロールチェンジなど、ノートオン以外のイベントはすべて
  そのまま通過します。

## パラメータ

| パラメータ | 範囲 | 使用モード | 説明 |
| --- | --- | --- | --- |
| Correct Type | Through / Fix / Remap / Clip | — | 補正モードの選択 |
| Velocity Fix | 0–127 | Fix | 固定するベロシティ値 |
| Velocity Min | 0–127 | Remap, Clip | 出力範囲の下限 |
| Velocity Max | 0–127 | Remap, Clip | 出力範囲の上限 |

- 各値はスライダーのドラッグ、または右側のテキストボックスへの数値入力
  (0–127)で設定できます。
- 現在のモードで使用しないスライダーは薄く表示され、操作できません。
- すべてのパラメータは DAW からのオートメーションに対応しています。

## ベロシティモニタ

GUI 右上の `in -> out` 表示は、最後に受信したノートオンの入力ベロシティと、
補正後の出力ベロシティをリアルタイムに表示します。

## GUI ズーム

プラグインウィンドウ上で右クリックするとコンテキストメニューが開き、
表示倍率を 100%〜200%(25% 刻み)から選択できます。
メニューをキャンセルした場合は現在の倍率が維持されます。
